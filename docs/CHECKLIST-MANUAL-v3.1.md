## Preparación y protección de datos

- [ ] Copiar guardados existentes con **Copias de seguridad JSON → Exportar** y comprobar que el archivo se descargó realmente.
- [ ] Cargar ranura antigua y comprobar cámara, vida, misiones, inventario, jefes ya vencidos y autoguardado.
- [ ] Guardar en tres ranuras manuales, cerrar navegador, reiniciar y recuperar cada una.
- [ ] Probar archivo inválido: debe mostrar error sin borrar datos.
- [ ] Importar JSON en otro perfil o puerto; confirmar que las ranuras no importadas se mantienen.
- [ ] Empezar nueva partida; comprobar que los guardados manuales anteriores siguen accesibles.

## Sistemas, jefes y finales

- [ ] Confirmar los **siete enfrentamientos regionales**, sus transiciones y recompensas.
- [ ] Probar Desvelo y puzles: Bosque, Ossara, Salmuera, Raíces, Cumbres y sellos finales, respetando las secuencias.
- [ ] Salmuera: natación, oxígeno, compuertas y recuperación tras muerte.
- [ ] Raíces Eternas: espinas en reposo, aviso y ataque; salto/plataforma y colisiones.
- [ ] Jefes: anticipación, alcance, daños, segundas fases, muerte y punto de reaparición.
- [ ] Llegar desde una partida nueva al **Primer Testigo** sin cargar estados preparados.
- [ ] Derrotar al Primer Testigo y comprobar los créditos y **tres desenlaces** desde guardados manuales separados.
- [ ] Comprobar que «Ver último desenlace» conserva un final aunque se inicie otra partida.
- [ ] Probar menú, guardado/carga, pausa por foco, Esc, controles de mando y desconexión/reconexión.
- [ ] Medir FPS de escenas con más enemigos, memoria, consumo CPU, audio y tamaño de caché en sesiones largas.
- [ ] Windows 11: doble clic del BAT, permisos, navegador, cierre y restauración de guardados.
- [ ] Linux Mint: doble clic o terminal de SH, Python 3, cierre correcto y restauración de guardados.
- [ ] Mando real estándar: navegación, ataques, esquiva, cambio de zona, menús y guardados.

## Registro de defectos

Para cada fallo, conservar: versión/OS/navegador, ranura de origen, sector, acción, resultado esperado, resultado observado, captura/video y pasos de reproducción. No marcar aprobado sin evidencia.
