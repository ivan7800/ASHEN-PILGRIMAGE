# Fuentes de arte v2.9

`giant-source.png` es una ilustración original generada para ASHEN PILGRIMAGE: el Gigante que Escucha en veinte poses. **No es un atlas ya listo para el motor**: `tools/build-summit-v29.py` recorta sus veinte celdas, elimina el fondo negro, ajusta su escala y crea `assets/bellgiant-v29.png`.

El mismo generador crea variantes diseñadas para el proyecto de dos enemigos a partir de los atlas glaciales de v2.8, y tres composiciones góticas a partir de las ilustraciones de las Cumbres de v2.8. Por tanto, estos enemigos no son veinte animaciones pintadas enteramente desde cero. Las tres composiciones nuevas son trabajos derivados de recursos originales de este proyecto, no de material comercial de terceros.

Regenerar con `python3 tools/build-summit-v29.py` desde cualquier ubicación. Requiere Pillow.
